# Explore Spring Framework

This repository contains **end-to-end learning and implementation of the Spring ecosystem**, starting from **Spring Core basics** to **advanced Spring Boot and Spring Data JPA concepts**.

It is a **practice-based repository** with multiple projects demonstrating real-world use cases and clean architecture.

---

## 📘 What You Will Learn

- Core concepts of **Spring Framework**
- Dependency Injection using **XML & Annotations**
- Bean lifecycle, scopes, and wiring
- Spring Boot application development
- REST API development using Spring MVC
- Database integration using **Hibernate & JPA**
- Multi-module Maven project structure

---

## 🧩 Modules Overview

### 🔹 project-1
- Spring Core fundamentals
- XML-based configuration
- Bean wiring using `ref` attribute
- Constructor & Setter Injection
- IoC Container behavior

### 🔹 project-2
- Annotation-based Spring configuration
- Spring Boot fundamentals
- RESTful APIs
- Spring Data JPA
- Entity mapping & relationships
- Exception handling
